# Release Checklist

1. Actualizar `bl_info["version"]` en `ManWTool.py`
2. Revisar `README.md`
3. Ejecutar `py build_addon.py`
4. Probar en Blender:
   - Registro del addon
   - Export FBX individual
   - Export FBX multiple
   - Import FBX con materiales
   - Comprobacion de updates
   - Activacion de licencia contra el servidor
5. Subir `ManWTool.zip` como asset de GitHub Release
6. Crear tag de version
