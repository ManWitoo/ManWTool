# ManWTool v1.0.11

## Cambios

- Aviso previo al aplicar transformaciones cuando se detectan meshes con escala negativa
- Deteccion de meshes cerradas con normales potencialmente invertidas
- Opcion para recalcular normales automaticamente durante la aplicacion de transformaciones
- Sincronizacion del repositorio de desarrollo con el repositorio publicado en GitHub

## Notas

- Esta release sustituye el estado local que habia quedado desalineado respecto a `v1.0.10`
- El ZIP publicado debe regenerarse desde esta version para mantener codigo y paquete alineados
