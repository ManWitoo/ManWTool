# ManWTool v1.0.12

## Cambios

- Aviso previo al aplicar transformaciones cuando se detectan meshes con escala negativa
- Deteccion de meshes cerradas con normales potencialmente invertidas
- Opcion para recalcular normales automaticamente durante la aplicacion de transformaciones
- Regeneracion del ZIP de distribucion desde un estado limpio del repositorio
- Limpieza de artefactos temporales y cache para mantener la release alineada con el codigo

## Notas

- Esta release sustituye la secuencia local no publicada que habia quedado entre `v1.0.10` y `v1.0.11`
- El asset `ManWTool.zip` incluido en GitHub Releases queda alineado con esta version
