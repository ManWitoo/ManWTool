# ManWTool v1.0.7

## Mejoras principales

- bloqueo por licencia: sin licencia activa solo queda accesible la pestaña `Resumen`
- proteccion extra en operadores para evitar usar funciones premium sin licencia
- updater endurecido para trabajar con releases y ZIPs validados
- base de licencias integrada en el addon
- soporte para modulo protegido compilable con Cython

## Cambios de producto

- la instalacion directa de updates sigue desactivada por defecto
- se mantiene `Debug logging` para soporte
- se conserva el flujo de release y comercializacion desde este repositorio

## Notas

- la activacion comercial requiere configurar `License Server`
- si compilas `manwtool_protected`, el ZIP de release lo incluira automaticamente
