# ManWTool v1.0.8

## Mejoras principales

- sistema multilenguaje base integrado en el addon comercial
- selector de idioma en preferencias con modo `Auto`
- nuevo flujo de naming con `Prefijo`, `Sufijo` o `Ambos`
- si eliges `Ambos`, aparecen dos campos para escribir prefijo y sufijo
- el preview del nombre final y `Aplicar nombre` usan la misma logica de composicion

## Cambios de producto

- el ZIP comercial ahora incluye `manwtool_i18n.py`
- se mantiene el bloqueo por licencia del addon comercial
- se conserva el flujo de release y distribucion desde este repositorio

## Notas

- el modo `Auto` usa el idioma de Blender cuando hay traduccion disponible
- esta version mantiene compatibilidad con el empaquetado comercial actual
